## 요청과 완료한 수정

사용자는 평가에서 발견한 데이터 유실부터 수정하고, 카드 분리·범위 처리·필터 해제, E6 후속 구조 정리, 전체 코드 리뷰와 실제 오류 수정, `ver2` 푸시를 순서대로 요청했다.

1. **재추출 합치기**: 항목 ID 기준으로 기존 편집·직접 추가 항목·근거·검증 기록을 유지하고 새 후보를 추가한다. 새 추출로 문서·코드 변경을 자동 승인하지 않는다. 문서·항목·중복 출처 상한을 넘으면 이전 상태를 유지하고 거부한다.
2. **V5 상태 분리**: 요약 카드를 구현 확인·구현됨·근거 없음·재확인 필요 네 개로 구성했다. 목록 배지·카드 수치·필터·상태 막대·범례·다음 행동은 공통 상태 기준을 쓴다. 넓은 화면 네 열, 좁은 화면 두 열 또는 한 열이다.
3. **범위 처리와 카드 해제**: 현재 목표의 포함 항목만 테스트 결과·이름 힌트·집계에 연결한다. 과거·참고 등 범위 밖 항목에는 제외 안내를 표시하며 기존 근거·테스트 이름 입력을 보존한다. 중복 출처 중 현재 목표가 있으면 범위에 포함된다. 활성 카드를 다시 누르면 전체 필터로 돌아가고 검색어를 지운다.
4. **E6와 캡슐화**: 화면 구성, 순수 상태 전이, Qt 연결, 항목 편집·문서 재확인, 범위·표시 상태를 분리했다. `App.tsx`·현황 화면·연결·이벤트 계약의 명시적 `any`를 제거했다.
5. **누적 리뷰에서 추가로 재현·수정한 오류**: 같은 렌더에 온 기준·추출 응답의 근거 유실, 연속 추출 응답의 후보 유실, 테스트 파일 선택 취소 후 잠금, 테스트 이름 편집 뒤 과거 연결 표시·지연 응답 적용, 제거된 현재 중복 출처의 범위 잔존을 수정했다.

문서 종류·V6 안내·기존 저장 파일 호환은 유지한다. 현황 수치는 사용자가 입력·확인한 근거 상태이며 실제 개발률이나 자동 판정 정확도가 아니다.
