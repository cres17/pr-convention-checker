## 서비스와 기존 완료 범위

Cross Agent는 Drift Gate 정책 엔진을 쓰는 데스크톱 앱이다. `.drift-gate.yml`로 API·환경변수·DB·인증·CI 변경과 동반 문서의 규칙을 검사한다. 기본 판정은 결정적 엔진이 담당하고 LLM은 선택형 추가 검토다. Python·YAML·Tree-sitter·GitHub Actions에 PySide6/Qt WebEngine·React/TypeScript·tool-ui 화면을 붙였다. FastAPI·Express 등은 적용 대상 예제이며 앱의 실행 프레임워크가 아니다.

구독 로그인한 Codex CLI·Claude Code로 추가 검토할 수 있지만 CLI 설치·로그인이 별도로 필요하다. MD에서 요구사항을 추출하고 코드 근거·수동 검증을 저장해 현황과 HTML/Markdown 보고서로 보여준다. 표시 수치는 사용자가 입력하고 확인한 근거 현황이며 자동으로 측정한 실제 개발률이 아니다.

과거 P06(문자열의 가짜 라우트), P10(HEAD), Markdown 표 B01은 `715335f`에서 실제 수정했다. 같은 12개 통제 사례는 지금도 12/12 충족한다. 32개 반례의 여러 줄 라우트 B01은 다른 사례이고 아직 미해결이다. v1 비교는 고정 응답 주입이며 실제 모델 정확도 비교가 아니다.

[Benchmark 수동 재검증 36805846668](https://github.com/cres17/pr-convention-checker/actions/runs/36805846668)도 성공했다. 데스크톱이 아닌 Action 릴리스의 보고서 첨부 단계는 이번 수동 실행에서 실행하지 않았으므로 실제 업로드 성공까지 검증했다고 표현하지 않는다. 실패했던 옛 실행 기록은 보존했다.
