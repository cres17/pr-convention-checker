# 현황 저장·복구 계약

확정 기준은 최대 120개 기능, 복구 초안은 최대 240개 기능이다. 자동 보관은 2MB, 내보내기/복구 파일은 16MB까지 허용한다. 직렬화는 UTF-8과 LF를 사용해 사전 계산한 바이트와 파일 바이트를 일치시킨다.

저장은 저장소 잠금 안에서 버전과 baseline 식별값을 비교한다. 다른 내용을 가진 같은 숫자 버전도 충돌이다. 기존 기준이 사라졌다면 오래된 편집을 암묵적으로 새 기준으로 저장하지 않는다. 같은 내용의 재시도는 버전을 올리지 않는다.

연결 문서 최대 10개와 보관 출처 최대 120개를 구분한다. 명시적 연결 해제는 기존 해시·목표·근거를 보존하고 현재 집계에서 제외한다. 보관 출처를 새로운 내용으로 위조하지 못하게 이전 확정 해시를 검사한다.

초안은 checkout·실행별로 분리한다. 삭제는 현재 revision과 실행 중 잠금을 확인한다. 종료된 사본에도 미저장 편집이 있을 수 있으므로 종료 여부만으로 자동 삭제하지 않는다. 사용자가 명시적으로 선택한 사본을 삭제한다.

확정 저장 이후 초안 정리·이력 기록 실패는 저장 성공과 별도로 경고한다. 손상 이력은 빈 파일로 덮어쓰지 않는다. 이력 비교는 검사 시작 시 읽은 목록을 사용한다. 원자 replace는 부분 JSON을 막지만 전원 장애 내구성까지 보장하는 것은 아니다.
