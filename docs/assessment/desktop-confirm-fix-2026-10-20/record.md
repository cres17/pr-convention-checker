- 무변경 판정: 조작 후 9~15초 뒤 `.drift-gate.yml`의 SHA-256(`8b7b2846…`)과 `git status`가 그대로인지 확인했다. 화면에도 저장 알림이 나타나지 않았다.
- "끄기 → 저장" 1회는 취소를 누르려다 좌표를 잘못 잡아 저장 버튼을 누른 것이다. 끄기 확인창은 예외 확인창보다 폭이 좁아 버튼 위치가 다르다. 전체 해상도 화면으로 위치를 다시 확인해 저장 버튼이었음을 확인했고, 저장 동작 확인으로만 집계했다. 같은 조건의 취소는 위치를 확인한 뒤 다시 시험했다.
- 같은 설치본에서 Finder 앱 아이콘, Dock 아이콘, 사이드바 로고가 새 도안으로 표시되는 것을 확인했다.

## 판단
- **사실:** 수정본 macOS arm64 설치본에서 취소 3회와 Esc 3회 모두 정책이 바뀌지 않았고, 저장을 누를 때만 바뀌었다.
- **사실:** 수정 전 문제의 원인이 macOS 기본 경고창의 반환값, 중복 호출, 원격 입력 방식 중 무엇이었는지는 확정하지 않았다. 수정은 세 경로를 모두 막는다. 기본 경고창 대신 Qt 대화상자를 쓰고, 누른 버튼 객체를 비교하고, 확인 중 들어온 요청을 거부한다.
- **확인하지 않음:** Windows와 macOS Intel 설치본의 수동 확인, 사람이 직접 누른 확인.
