PR 파일럿 label 도구

사용법

  1. 맨 위에 reviewer_id를 적습니다(모든 답에 같은 값이 들어갑니다).
  2. 항목마다 ①문제 ②설명 ③볼 곳 ④선택을 순서대로 읽고 label을 고릅니다. 근거는 한 줄이면 됩니다.
  3. 고르는 즉시 이 브라우저에 자동 저장됩니다. 저장 후 다음은 다음 항목으로 넘어갑니다.
  4. 끝나면 JSONL 내보내기로 파일을 받아 대화에 첨부합니다. 중간에도 내보낼 수 있습니다.

단축키: 숫자 1~4는 선택지, ←/→는 이전/다음 항목, Ctrl+Enter는 저장 후 다음. 입력칸에 커서가 있으면 숫자·화살표는 동작하지 않습니다.

저장 위치: 브라우저 저장소(이 파일을 연 브라우저). 브라우저 데이터를 지우면 사라지니 가끔 내보내세요. 저장 파일 지정을 쓰면(Chrome·Edge) 답할 때마다 지정한 .jsonl 파일에 덮어씁니다.

Drift Gate를 실행하거나 결과를 찾아보지 마세요. 이 도구는 엔진 출력을 갖고 있지 않습니다.
