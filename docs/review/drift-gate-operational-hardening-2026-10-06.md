## 반영한 동작

- 정책 탐색: 로컬 루트 기준 기본 정책, 호출 위치 기준 명시 정책, 원격 PR 모드의 독립 입력. 정책을 한 번 읽어 출력 원문과 평가가 일치한다. check/desktop에서 빈 규칙은 오류다.
- 정책 스키마: 중복 키·오타 키·누락 id·잘못된 리스트/boolean/문자열·0/음수/소수/bool 실패 임계값을 거부한다. YAML 크기·깊이·alias·event 한도를 둔다. merge 키는 미지원으로 명시한다.
- 오류 산출물: CLI와 self-check 입력 오류는 종료2 및 새 실행 ID가 있는 JSON을 원자 기록한다. self-check 내부 오류는 traceback·execution_error·종료3이다. 출력 쓰기 실패·프로세스 강제 종료까지 새 파일을 보장하지 않는다.
- 경로 역할: rename 이전/현재 경로로 trigger와 ignore를 판단한다. 이전 보호 경로를 목적지 docs/tests로 옮겨 검사를 생략하지 않는다. 문서 충족은 현재 경로를 사용한다. docs/test 전용 변경도 명시 규칙이 있으면 평가한다.
- 주석: 공통 prefix로 `*extra`/`**options`/`#define`을 삭제하지 않는다. Python 로컬 검사는 bounded before/after 원문을 사용한다. 원문 없는 API/fixture의 diff 토큰 판단은 휴리스틱이며 hunk 밖 문자열 문맥을 완전히 보장하지 않는다. 미지원 언어의 주석은 경고 증가 가능성을 보수적으로 유지한다.
- 비교·보고: commit과 merge-base 모드를 분리했다. 실행 ID·정책 digest·head/base·dirty·제외된 미등록 파일 목록·skip/no_policy를 보존하고 evaluated_rules를 실제 적용 수로 고쳤다.
- self-audit: schema2 상태는 related-evidence-found/no-related-evidence/unchecked다. 관련 참조는 행동 검증이 아니며 behavior_verified=false를 명시한다. 경로 조각 매칭을 제거했다.
- MCP: 내부 결과에도 strict JSON을 적용하고 비유한 숫자를 거부한다. 알림 무응답·파싱 오류 envelope를 수정했다. stdio 서버는 시작 때 허용 저장소 루트를 고정하며 외부/심볼릭 링크 경로와 큰 파일을 거부한다.
- 자체 검사: 선언된 운영 범위의 미분류 변경, 없는/빈 필수 계약을 거부한다. 파서·정책·데스크톱·빌드 설정의 누락 범위를 추가했다. 고정 정책 의무와 비교해 8가지 완화를 거부한다.
- 설치본 검증: 처음8언어 분석에 이어 실제 QWebChannel 검사로 유효 가변 인자 추가와 src→docs rename을 수행한다. 두 반례가 PASS이면 CI 설치본 검증이 실패한다.
