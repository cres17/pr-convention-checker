# 초안 관리 보완과 검증 (2026-10-02)

기준 커밋은 `517abef`입니다. 기존 충돌 저장 방지와 실행별 초안 보존을 유지하면서, 삭제 계약·실행 중 보호·사본 정리·합치기 상한 초과 시 복구 경로를 보완했습니다.

## 변경

- `discard_recovery`는 빈 수정 버전을 거부합니다. 개별·일괄 삭제가 같은 함수를 사용하고, 선택 전체의 경로·수정 버전·실행 상태를 삭제 전 잠금 안에서 확인합니다. 하나라도 검증에 실패하면 아무 사본도 삭제하지 않습니다. 실제 파일 삭제 중 디스크 오류는 일부 삭제 후 발생할 수 있습니다.
- 초안 트랜잭션은 저장소별 하나의 영구 `.json.lock`을 사용합니다. 이 파일을 삭제하지 않습니다. 예전 소유자별 `.json.lock`도 이전 실행과의 잠금 충돌을 피하려고 자동 삭제하지 않습니다. 새 소유자별 트랜잭션 잠금은 만들지 않습니다.
- 별도 `.live.lock`을 실행별로 보유합니다. 획득·비차단 확인·정리는 같은 저장소 게이트 안에서만 진행하고, 수명 잠금에는 기다리는 요청을 두지 않습니다. 정상 종료 시 해제·제거하며, 비정상 종료 시 OS가 해제하고 다음 복구 조회가 파일만 정리합니다. 초안 데이터는 자동 삭제하지 않습니다.
- 복구 화면에서 실행 중 사본을 구분하고 복구·삭제를 막습니다. 사본 수와 총 용량을 표시하며 20개부터 선택 정리를 안내합니다. 사용자가 선택한 종료 사본만 삭제합니다. 다른 실행의 사본을 보존한 채 확정 기준을 편집하는 동작도 제공합니다.
- 합친 결과가 문서 10개·기능 120개를 넘으면 내 초안을 JSON으로 내보내고 최신 기준으로 전환할 수 있습니다. 불완전한 입력과 원래 편집 기준까지 보존합니다. 실제 파일 읽기 확인 뒤 전환을 허용하고 전환 때 해시·존재 여부를 재검사합니다. 내보내기 취소·실패·추가 편집은 전환을 허용하지 않습니다.
- 최신 기준 전환은 현재 확정 기준을 다시 읽습니다. 지연된 자동 보관 타이머·응답을 취소하고, 다른 저장소로 이동한 뒤 완료돼도 원래 세션을 갱신합니다.

## 범위와 한계

- 실행 중 보호는 이 버전의 앱 간에 적용됩니다. 실행 수명 잠금을 구현하지 않은 이전 버전의 앱은 활성 여부를 판별할 수 없습니다.
- 사본 개수와 오래된 초안 데이터는 자동으로 줄이지 않습니다. 저장소별 게이트 하나와 현재 실행의 수명 잠금이 남으며, 종료한 실행의 수명 잠금 파일은 정리합니다.
- JSON 초안 백업을 앱으로 가져오는 화면은 이번 범위에 없습니다. 파일 자체는 전체 편집과 원래 기준을 보존합니다.
- 실제 최종 사용자 Windows/macOS 설치·사용성은 검증하지 않았습니다. 로컬 Qt 검증은 소스 호스트의 임시 저장소 실행입니다.
- 이번 작업은 편집 안전성과 사용 흐름 보완입니다. 기존 합성 평가를 재실행하지 않았고 판정 정확도 향상을 주장하지 않습니다. 공개 미리보기 릴리스도 갱신하지 않습니다.
